# CTVista

A bilingual English–Persian research demonstration for AI-assisted chest CT review.

The application provides:

- an interactive CT slice viewer;
- an on-demand lightweight 3D visualization;
- AI-assisted review prioritization;
- a structured review checklist;
- a prototype similar-case workflow;
- draft findings for radiologist verification.

## Important

This is a research and investor demonstration. It is not intended for clinical diagnosis or patient care.
